# Dinesh — Pulizie B&B (Bologna)

Landing page pensata per host italiani (B&B e case vacanza) e per condivisione su Facebook.

## Come aprire

- Apri `dinesh-bb-cleaning/index.html` nel browser.

## Cosa personalizzare (importante)

1. **Numero di telefono / WhatsApp**
   - Apri `dinesh-bb-cleaning/script.js`
   - Cambia `CONFIG.phoneDigits` con il numero reale **senza `+` e senza spazi**.
   - Esempio: `393331234567`

2. **Testo WhatsApp precompilato**
   - In `dinesh-bb-cleaning/script.js`, modifica `CONFIG.waDefaultText`

3. **Zona servita**
   - In `dinesh-bb-cleaning/index.html` cerca “Zona servita” e aggiorna la frase.

## File principali

- `index.html` — contenuti e sezioni
- `styles.css` — stile moderno e responsive
- `script.js` — link WhatsApp/tel + copia messaggio + toast
- `assets/og-image.svg` — immagine social per Facebook (OpenGraph)

## Media stock (temporanei)

In `assets/media/` ho aggiunto foto/video stock gratuiti da Pexels per aumentare fiducia nelle condivisioni Facebook.

Consigliato: sostituire con foto/video reali (prima/dopo, finestre, bagno, letto) appena possibile.
